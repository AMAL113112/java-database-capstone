# User Stories

## Doctor User Story 1
Title: As a Doctor, I want to log in securely so that I can access my dashboard safely.

### Acceptance Criteria
1. Doctor can log in using email and password.
2. Invalid login should show an error message.
3. Successful login redirects to doctor dashboard.

Priority: High  
Story Points: 5

---

## Doctor User Story 2
Title: As a Doctor, I want to view my appointments so that I can manage my daily schedule.

### Acceptance Criteria
1. Doctor can view all booked appointments.
2. Appointment list shows patient name and appointment time.
3. Doctor can update appointment status (completed, cancelled, no-show).

Priority: High  
Story Points: 5

---

## Patient User Story 1
Title: As a Patient, I want to search doctors by specialty so that I can find the right doctor easily.

### Acceptance Criteria
1. Patient can search doctors by specialty.
2. Matching doctors should be displayed.
3. Doctor availability should be visible.

Priority: High  
Story Points: 5

---

## Patient User Story 2
Title: As a Patient, I want to book appointments so that I can consult a doctor.

### Acceptance Criteria
1. Patient can select a doctor.
2. Patient can choose an available appointment time.
3. Booking confirmation should be shown after successful booking.

Priority: High  
Story Points: 5

---

## Admin User Story 1
Title: As an Admin, I want to add doctors so that new doctors can join the clinic system.

### Acceptance Criteria
1. Admin can enter doctor details.
2. Admin can assign specialty and availability.
3. Newly added doctor appears in doctor list.

Priority: High  
Story Points: 4

---

## Admin User Story 2
Title: As an Admin, I want to manage doctors and patients so that the system remains updated.

### Acceptance Criteria
1. Admin can view doctor and patient records.
2. Admin can update doctor information.
3. Admin can manage user accounts.

Priority: Medium  
Story Points: 4
