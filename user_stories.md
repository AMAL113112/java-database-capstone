# User Stories

## Doctor User Story
Title: As a Doctor, I want to view my appointments so that I can manage my daily schedule.

### Acceptance Criteria
1. Doctor can log in securely.
2. Doctor can view all booked appointments.
3. Doctor can update appointment status.

Priority: High  
Story Points: 5

---

## Patient User Story
Title: As a Patient, I want to search doctors by specialty so that I can book appointments easily.

### Acceptance Criteria
1. Patient can sign up and log in.
2. Patient can search doctors by specialty.
3. Patient can book appointments.

Priority: High  
Story Points: 5

---

## Admin User Story
Title: As an Admin, I want to manage doctors and patients so that the system remains updated.

### Acceptance Criteria
1. Admin can add doctors.
2. Admin can update doctor information.
3. Admin can manage users.

Priority: High  
Story Points: 6
